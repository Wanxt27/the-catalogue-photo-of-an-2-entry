## The product

**EVERLAST™** — a single AA battery, metallic gold and white, standing upright
in the centre of a clean studio shot. A glowing infinity symbol wraps its body
and a tiny digital screen reads "100% — FOREVER". It impossibly powers five
things at once through tiny glowing cables: a phone, a lamp, a toy car, a TV
remote, and a drone, all floating around it.

The catalogue page carries the full treatment: "EVERLAST™" top left,
"CATALOGUE No. 0341" top right, a spec box (Price $9.99 / Power: INFINITE /
Charges from thin air / Never dies, never leaks, never needs replacement /
Fits ALL devices), a red starburst badge reading "IMPOSSIBLE! BUT REAL", a
barcode, and "MAKE.FUN CATALOGUE — 2026" along the bottom. The make.fun ghost
mascot, in a lab coat, holds the battery up like a scientist showing it off.

## How it works

`main.ts` (Node 22, no network) copies `entry.png` from this repository to
`/output/entry.png`:

```sh
node main.ts
```

The image is a 4:5 portrait catalogue photo, 819×1024, ready for the judge.
